Acquisti in-app

Yamadori Pro è un acquisto una tantum gestito da Google Play Billing. Le transazioni sono elaborate da Google; Yamadori non raccoglie né conserva i dati di pagamento. Solo un token di acquisto resta sul dispositivo per attivare le funzioni Pro.

I tuoi diritti

Yamadori non crea account utente e non invia i tuoi dati di scouting a un server dell’editore. Puoi consultare, modificare ed eliminare i dati direttamente nell’app (alberi, foto, note vocali, cache). Per domande, contattaci all’indirizzo sopra.

Manifesto Yamadori

Yamadori non sincronizza i tuoi rilevamenti nel cloud. Il tuo taccuino da campo sta in tasca.

Sul tuo dispositivo

Il tuo taccuino, il tuo telefono

Nessun account, nessun server Yamadori. I tuoi rilevamenti, foto, note vocali e punto di partenza restano su questo dispositivo. Di default i dati sono salvati senza cifratura nello storage locale; puoi attivare la cifratura locale in Impostazioni (opzionale, Android) — protegge alberi, parcheggio, password di export e impostazioni GPS, ma non le cache meteo o mappa.

Pensato per la foresta

Mappa, meteo e catasto vengono memorizzati in cache in locale. Il GPS funziona senza rete — anche in fondo al bosco.

Proteggi il tuo taccuino

Esporta regolarmente un backup (chiavetta USB, cloud personale). Senza password di export, il file garantisce solo l’integrità (checksum), non la riservatezza: chiunque abbia il file può estrarre i dati. Con una password, l’intero archivio è cifrato (PBKDF2 + AES-GCM). Il promemoria è solo un aiuto memoria; non può recuperare la password.

Piena trasparenza

Come un taccuino cartaceo in borsa, i tuoi rilevamenti restano leggibili su un dispositivo sbloccato. Yamadori non usa il backup automatico Android verso Google. Consigliamo un blocco schermo ed export protetti da password.

Autorizzazioni Android

Fotocamera: solo foto degli alberi, quando premi Cattura. Microfono: note vocali (max 30 s), su tua azione. Posizione: rilevamento, mappa e meteo, solo quando l'app è in primo piano. Bussola: visualizzazione del cap durante la cattura, elaborata in locale. La procedura guidata permessi al primo avvio ti accompagna — nulla viene richiesto senza motivo.

In linea

Connessione minima

Online, solo le coordinate GPS vanno a servizi pubblici per meteo, agronomia, mappe, catasto, aree protette e geocodifica — mai le tue foto o note. Per paese: Open-Meteo, IGN / CNIG / basemap.de / OS / swisstopo / basemap.at / OpenTopo (BE, SE, JP, AU, DK, FI, IE, CA, NZ) / PDOK BRT (NL) / Kartverket (NO) / USGS (US), EEA, Natural England, UFAM, CadGIS, Nominatim (OpenStreetMap), e altri.

Servizi terzi consultati

Open-Meteo (previsioni e storico climatico; uso commerciale con abbonamento dell’editore), mappe nazionali (IGN FR, CNIG ES, basemap.de, Ordnance Survey / OSM, swisstopo CH, basemap.at AT, OpenTopo BE/SE/JP/AU/DK/FI/IE/CA/NZ, PDOK BRT NL, Kartverket NO, USGS US), catasto (IGN Apicarto, Catastro ES, Catasto IT, ALKIS DE parziale, HMLR GB, AV/EGRID CH + AVWFS ZH, comune AT, CadGIS BE, BRK NL, kommun SE, matrikkel NO, DGT PT, Nominatim DK/FI/IE/JP, CAPAD AU, PAD-US, CPCAD CA, DOC NZ), aree protette (IGN FR, EEA, Natural England, UFAM/Pro Natura CH, CAPAD AU, MOE/KSJ A10 JP, PAD-US, CPCAD CA, DOC NZ), Nominatim/OpenStreetMap (toponimi), elenchi comunali per paese. Yamadori non ha server intermediario: le coordinate vanno direttamente a questi servizi pubblici, ciascuno con la propria privacy. Foto e note non lasciano il dispositivo così.

Nessun tracciamento

Nessun account Yamadori, nessuna pubblicità, nessuna analitica (Firebase, crash reporter, ecc.). Nessuna rivendita di dati. Nessun cookie di terzi: l'app gira in locale in una WebView Android.

Hai il controllo

Decidi tu chi vede i tuoi spot

Condividere un albero o esportare un backup è una scelta tua. Nulla viene inviato automaticamente a terzi.

GPS trasparente

In primo piano, il GPS serve a rilevare un albero, mostrare la mappa e contestualizzare il meteo. Il tracciamento si interrompe quando l’app è in background. Nessuna posizione viene inviata a un server Yamadori.

Tagli la rete

Ogni connessione di rete è disattivabile singolarmente in Impostazioni. Se disattivi un'API, nessuna richiesta in diretta; la cache già scaricata resta consultabile offline.

Inventario dei dati

Cosa gestisce Yamadori per il tuo taccuino da campo — dove è archiviato, cosa va online e come eliminarlo.

Coordinate GPS

Archiviato sul dispositivo (alberi, parcheggio, posizione). Inviato online: solo latitudine/longitudine verso le API attive. Condivisibile via export o condivisione albero. Eliminazione: elimina l'albero o svuota le cache in Impostazioni.

Foto

Archiviato sul dispositivo. Mai inviato online da Yamadori. Condivisibile via export o condivisione albero. Eliminazione: elimina l'albero.

Note vocali

Archiviato sul dispositivo. Mai inviato online. Condivisibile solo via export di backup. Eliminazione: elimina l'albero.

Meteo e clima

Memorizzato in cache in locale dopo una richiesta. Coordinate inviate a Open-Meteo se l'API è attiva. Non condiviso. Eliminazione: Impostazioni → svuota cache meteo.

Tasselli mappa

Cache locale. Richieste di tasselli per l’area visibile per paese (IGN, CNIG, basemap.de, OS…). Non condiviso. Eliminazione: Impostazioni → svuota cache mappa.

Catasto e aree protette

Cache locale. Coordinate inviate ai servizi nazionali di catasto / aree protette se abilitati. Non condiviso. Eliminazione: Impostazioni ? svuota cache catasto.
